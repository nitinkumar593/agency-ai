
# Agency.ai 🚀

A modern, fully responsive and animated agency landing page built with React, Tailwind CSS, and Motion.

🌐 **Live Demo:** [Visit Agency.ai](https://agency-ai-five-phi.vercel.app/)

## ✨ Features

- 📱 Fully responsive design for mobile, tablet, and desktop
- 🎨 Modern and clean user interface
- 🎬 Smooth animations and transitions
- 🌙 Light and dark theme
- ⚡ Reusable React components
- 🖱️ Interactive UI elements
- 📐 Responsive layouts for different screen sizes

## 🛠️ Tech Stack

- **React** — Component-based UI development
- **Tailwind CSS** — Utility-first CSS framework
- **JavaScript** — Interactive functionality
- **Motion** — Smooth animations and transitions
- **Vite** — Fast development and build tool

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm

### 1. Clone the Repository

```bash
git clone https://github.com/nitinkumar593/agency-ai.git
```

### 2. Navigate to the Project Directory

```bash
cd agency-ai
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the website.

### 5. Build for Production

```bash
npm run build
```
